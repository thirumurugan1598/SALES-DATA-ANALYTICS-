📊 Insurance Customer Analytics Dashboard

An interactive Insurance Customer Analytics Dashboard built using Microsoft Excel to analyze customer demographics, income, occupation, marital status, insurance coverage, and policy-related metrics.

The dashboard transforms raw insurance customer data into meaningful visual insights that can support data-driven business analysis and decision-making.

---

🚀 Project Overview

Insurance companies manage large amounts of customer and policy data. Analyzing this information manually can make it difficult to identify customer patterns, understand coverage behavior, and monitor important business metrics.

This project provides an interactive Excel dashboard that organizes and visualizes insurance customer information in a simple and understandable format.

The dashboard focuses on:

- Customer demographics
- Customer income analysis
- Occupation-based analysis
- Marital status distribution
- Insurance coverage analysis
- Policy-related metrics
- Customer segmentation
- Interactive data visualization

---

🎯 Objectives

The main objectives of this project are:

1. Analyze insurance customer demographics.
